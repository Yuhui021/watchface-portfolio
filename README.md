## 设计与功能

- 顶部显示日期与星期，大号数字采用 24 小时制。
- 绿色眼睛约每 4.4 秒完成一次眨眼循环，底部为静态尖牙笑脸。
- 亮屏时分钟自动更新；普通息屏后再次唤醒立即同步时间。
- 本版专注时间与动态视觉，无天气、计步、电量等数据项。
